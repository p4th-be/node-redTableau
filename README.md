# node-red

Dans cette archive, vous trouverez un projet de Digital Signage développé avec Node-RED.  
Le système permet la gestion et l’affichage de contenus numériques tels que des images, vidéos, textes et informations en temps réel de manière automatisée et centralisée.

Le projet inclut :
- Flux automatisés avec Node-RED
- Gestion dynamique du contenu
- Intégration avec APIs et services externes
- Interface simple et personnalisable
- Solution légère et flexible pour affichage digital

Ce repository sert comme base de développement, d’apprentissage et d’amélioration pour des solutions de Digital Signage.
